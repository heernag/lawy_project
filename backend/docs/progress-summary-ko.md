# 백엔드 진행 현황 요약

작성일: 2026-07-15

## 현재 상태

현재 백엔드는 무료 버전 MVP 구조입니다.

사용 중인 방식:

- FastAPI
- SQLite
- 샘플 판결문 데이터
- 로컬 규칙 기반 사건 분석
- 로컬 키워드 검색
- 로컬 검증 로직
- 로컬 문서화

사용하지 않는 것:

- 유료 LLM API
- 유료 임베딩 API
- 유료 벡터 DB
- 유료 판결문 API
- 무단 크롤링
- 승소/패소 예측

## 현재까지 완료된 것

### 1. 기본 백엔드 구조

- FastAPI 서버 구조 생성
- API 라우트 분리
- 공통 성공/실패 응답 형식 적용
- CORS 설정
- `.env.example` 작성
- README 작성
- Swagger/OpenAPI 문서 제공

### 2. 판결문 데이터 저장

- 샘플 판결문 데이터 로드
- SQLite DB 저장
- 판결문 상세 정보 저장
- 섹션/문단 저장
- 요약 결과 저장 및 재사용
- 법률 용어 DB 저장
- 판결문 검색 인덱스 저장

### 3. 자연어 사건 분석

- 사용자가 입력한 사건 문장 분석
- 사건 분야/유형 분류
- 당사자 추출
- 주요 사실관계 추출
- 법적 쟁점 추출
- 검색 키워드 추출
- 법률 용어 후보 추출
- 사용자가 말하지 않은 사실은 추가하지 않도록 테스트

### 4. 개인정보 및 입력 안전

- 전화번호 마스킹
- 주민등록번호 형식 마스킹
- 이메일 마스킹
- 명확한 한국 도로명 주소 마스킹
- 금액 표현을 주소로 잘못 가리는 문제 방지
- 프론트에서 보여줄 `sanitized_query` 제공
- 프롬프트 인젝션 의심 문구 경고

### 5. 판결문 검색

- 사건번호 정확 검색
- 키워드 검색
- 사건 분야 필터
- 법원/판결 결과 필터 구조
- 선고일 필터
- 검색어 정규화
- 저장된 검색 인덱스 사용
- 유사 판결문 조회
- 무료 로컬 해시 임베딩 검색 구현 및 커밋 완료

### 6. 판결문 상세 조회와 문단 분리

- 판결문 상세 조회 API
- 원문 섹션 분리
- 문단 단위 분리
- 안정적인 문단 ID 생성
- `주문`, `청구 취지`, `이유`, `인정 사실`, `원고 주장`, `피고 주장`, `법원의 판단`, `결론`, `관련 법령` 인식
- 번호가 붙은 제목 인식
- `항소취지`, `항소이유`, `상고이유` 인식

### 7. 쉬운 설명 생성과 검증

- 문단별 쉬운 설명 생성
- 원문과 쉬운 설명 연결
- 검증 상태 반환
- 금액 검증
- 날짜 검증
- 사건번호 검증
- 이자율/비율 검증
- 법률 조항 번호 검증
- 원고/피고 역할 변경 검증
- 지급 의무 주체 변경 검증
- 기각/인용 등 판결 결과 변경 검증
- 부정 표현 누락 검증
- 원문에 없는 사실 추가 검증

### 8. 법률 용어와 요약

- 법률 용어 조회 API
- 판결문 내 법률 용어 추출
- 문단 ID와 연결된 법률 용어 추출
- 판결문 요약 생성
- 이미 만든 요약 재사용

### 9. 에러 처리와 프론트 연동

- 공통 에러 응답 형식 적용
- 요청 검증 오류를 `INVALID_REQUEST`로 통일
- 잘못된 JSON도 공통 에러 형식으로 반환
- 운영 환경에서는 상세 검증 정보 숨김
- 에러 코드 상수 관리
- `ALL_ERROR_CODES` 제공
- 프론트용 TypeScript 타입 예시 작성
- 검증 실패 응답 예시 작성
- 전체 API 체크리스트 작성
- Bruno 테스트 컬렉션 작성
- 프론트 화면 흐름 가이드 작성
- README 기준 실행 검증
- MVP 최종 점검표 작성

### 10. 헬스 체크

- `/api/health`
- 판결문 공급자 상태 확인
- 샘플 데이터 로드 여부 확인
- 공급자 오류 시 내부 예외 숨김
- 헬스 체크 로직을 `HealthService`로 분리

## 앞으로 남은 핵심 작업

### 반드시 해야 하는 것

- 최종 전체 테스트 실행

### 하면 좋은 것

- 주소 마스킹 테스트 추가
- 판결문 제목/섹션 분리 테스트 추가
- 프론트가 자동 생성 타입을 쓰게 되면 OpenAPI 계약 검증 추가
- 필요하면 헬스 체크에 DB/검색 인덱스 상태 확인 추가

### 무료 MVP 이후로 미뤄도 되는 것

- 공식 공공데이터 API 연동
- 더 강한 무료 로컬 임베딩 모델 검토
- Alembic 마이그레이션 운영 정리
- 더 많은 실제 공개 판결문 샘플 추가
