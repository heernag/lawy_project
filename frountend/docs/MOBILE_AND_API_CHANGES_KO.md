# 수정 내용

## 모바일
- 820px 이하에서 홈/판례검색/생활법률 장식 이미지 숨김
- 모바일 헤더를 `CaseFinder + 햄버거` 중심으로 축소
- 햄버거 안에 주요 메뉴와 내 메뉴를 모두 배치
- 판례 검색 카테고리를 가로 스크롤로 제공
- 판례 결과 카드의 법원/선고일/사건번호를 모바일에서 세로 정렬
- 검색 요약은 모바일에서 최대 3줄 표시
- 판례 상세 탭은 가로 스크롤, 원문은 작은 화면에서 자동 줄바꿈

## 판례 백엔드 연동
- 판례 목록을 하드코딩 데이터 대신 `/api/cases/search` 결과로 표시
- 판례 상세를 `/api/cases/{case_id}` 및 요약/쉬운설명/법률용어/유사판례 API와 연결
- 대용량 데이터셋을 고려해 페이지 버튼은 최대 5개만 계산/표시
- NIA 데이터용 사건 분야 필터 추가: 민사, 형사, 가사, 노동, 행정, 특허, 개인정보, 금융조세, 기업
- 법원명 직접 입력 및 시작일/종료일 필터 지원
- `similarity_score`는 승소율이 아닌 `검색 관련도`로 표시
- 홈의 가짜 최근 판례를 제거하고 실제로 사용자가 열어본 판례를 localStorage에서 표시
